# HTMLwebLearning

一个原生 HTML/CSS 页面练习，以《鸣潮》角色四联屏宣传页为示例，练习响应式网格、图片裁切、渐变叠层和悬停效果。入口是 [index.html](index.html)，样式和少量图片加载失败处理脚本都写在同一文件中。

## 本地预览

可直接用现代浏览器打开 `index.html`，并保留它与 `assets/` 的相对位置。项目没有 npm 依赖、构建步骤或后端服务。

如果希望通过 HTTP 预览，并且已安装 Python 3，在项目根目录执行：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

如果命令名为 `python3`，替换上面的 `python`。随后打开 <http://127.0.0.1:8000>，结束预览时按 `Ctrl+C`。该命令只监听本机回环地址。

## 资源与样式

- 四张角色图保存在 [assets/characters/](assets/characters/) 中，由页面使用相对路径加载。调整文件名或目录时，需要同步修改图片的 `src`
- 字体通过 Google Fonts 的 CSS 导入加载 `Bebas Neue` 和 `Noto Serif SC`，需要联网；加载失败时会使用代码中声明的系统字体回退，字形与排版可能有所差异
- 每个 `.panel` 的内联 CSS 变量控制色调、图片焦点、缩放和偏移；修改这些值可以调整构图
- 图片触发加载错误时，脚本会为对应面板添加 `is-fallback`，显示文字占位
- 仓库未提供许可证或图片来源说明；此文档不授予代码或素材的再分发授权。需要复用或发布素材时，应先核实来源与使用许可

## 手工检查清单

当前没有自动化测试或 CI 配置。修改页面后，建议在浏览器中检查：

- [ ] 宽度大于 `980px` 时显示四列，四张图片和角色文字均可见
- [ ] 宽度在 `621–980px` 时显示两列，页面可向下滚动
- [ ] 宽度不超过 `620px` 时显示单列，文字和图片没有意外溢出或遮挡
- [ ] 鼠标悬停每个面板时，对应立绘变暗并轻微缩放，移开后恢复
- [ ] 触屏设备没有持续悬停时，仍能阅读基础角色信息
- [ ] 在开发者工具中临时阻止一张图片请求并刷新，确认对应文字占位出现，其他面板不受影响
- [ ] 字体不可用时，系统字体回退仍能让内容保持可读

页面使用 `color-mix()`、`backdrop-filter` 等 CSS 特性；不同浏览器的视觉效果可能不同，发布前需要实际预览。这份清单不代表已经完成跨浏览器或响应式视觉测试。
